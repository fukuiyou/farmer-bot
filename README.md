# All-Purpose Bot (farmer-bot)

A hands-free automation mod for Minecraft Fabric: summon your own robot worker, select farmland with a stick and it will till, plant, bonemeal, harvest and replant on its own; select a forest with an axe and it chops trees, pillars up, tears the column down and replants saplings; select a ranch with shears and it collects eggs, shears wool and feeds animals automatically. It can also mine along designated tunnels (scanning for lava before digging and climbing back to the surface when done), clear hostile mobs in a marked zone, and build structures from 50 built-in blueprints. If you get hit it fights back, and if you start a fight it joins in — bare fists when no sword is around. It follows you anywhere, teleporting across dimensions to keep up, comes with 200 original skins to choose from, and every feature can be toggled in the frosted-glass settings panel (press / or G). With your own Moonshot API key you can even chat with it directly in the built-in chat window.

Requires MC Java 1.21.11, Fabric Loader and the HeroBot dependency.

Inspired by the original Farmer Bot mod. Rewritten and expanded with new features.
